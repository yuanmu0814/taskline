# 数据库连接问题排查指南

## 常见问题及解决方案

### 1. sqlite3 模块安装失败

**问题**: 在 Linux 服务器上安装 sqlite3 时可能失败，因为需要编译原生模块。

**解决方案**:

#### Ubuntu/Debian:
```bash
sudo apt-get update
sudo apt-get install build-essential python3
cd server
npm install sqlite3
```

#### CentOS/RHEL:
```bash
sudo yum install gcc gcc-c++ python3
cd server
npm install sqlite3
```

#### 如果仍然失败，尝试:
```bash
npm install sqlite3 --build-from-source
```

### 2. 数据库文件权限问题

**问题**: 数据库文件或目录没有写入权限。

**解决方案**:
```bash
# 确保 data 目录存在且有权限
mkdir -p data
chmod 755 data

# 如果数据库文件已存在，设置权限
chmod 644 data/taskline.db
```

### 3. 使用更好的 SQLite 库（推荐）

如果 sqlite3 在服务器上安装困难，可以使用 `better-sqlite3`:

```bash
cd server
npm uninstall sqlite3
npm install better-sqlite3
```

然后修改 `server/index.js` 中的导入:
```javascript
import Database from 'better-sqlite3';
```

### 4. 检查数据库文件路径

确保数据库文件路径正确，检查日志中的路径:
```
数据库文件路径: /path/to/taskline/data/taskline.db
```

### 5. 使用绝对路径（可选）

如果相对路径有问题，可以在 `.env` 中设置:
```bash
DB_PATH=/absolute/path/to/data/taskline.db
```

然后在代码中使用:
```javascript
const DB_PATH = process.env.DB_PATH || join(__dirname, '..', 'data', 'taskline.db');
```

## 快速诊断命令

```bash
# 检查 sqlite3 是否安装
cd server
node -e "require('sqlite3')"

# 检查数据库文件
ls -la data/taskline.db

# 测试数据库连接
sqlite3 data/taskline.db "SELECT 1;"
```

## 使用 better-sqlite3（推荐方案）

如果 sqlite3 一直有问题，建议切换到 better-sqlite3，它更稳定且不需要编译:

1. 安装:
```bash
cd server
npm install better-sqlite3
```

2. 修改代码（已提供 better-sqlite3 版本的代码）
